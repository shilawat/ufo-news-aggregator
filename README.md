# UFO News Aggregator

Real-time UFO and UAP news aggregator powered by Claude AI and web search.

## Features

- 🔍 Real-time news search
- 🛸 UFO and UAP focused
- 🌐 Multiple news sources
- 📱 Responsive design
- ⚡ Fast and lightweight

## Local Development

1. Install dependencies:
   \`\`\`bash
   npm install
   \`\`\`

2. Start development server:
   \`\`\`bash
   npm start
   \`\`\`

3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Build for Production

\`\`\`bash
npm run build
\`\`\`

## Deploy to Netlify

\`\`\`bash
netlify deploy --prod
\`\`\`

## Technologies Used

- React 18
- Tailwind CSS
- Lucide Icons
- Anthropic Claude API
- Web Search Tool
